# DSA Roadmap Tracker

A free interactive Data Structures and Algorithms roadmap for beginners.

## Live Website

https://dsa-roadmap-tracker.onrender.com/

## Features

- Step-by-step DSA roadmap
- Big-O notation and complexity analysis
- Arrays and strings
- Hash tables and linked lists
- Stacks, queues and deques
- Recursion and backtracking
- Binary trees, BSTs, heaps and tries
- Graphs, BFS, DFS and Dijkstra
- Sorting and binary search
- Greedy algorithms
- Dynamic programming
- Topic checklists
- Practice problems
- Search and status filters
- Progress tracking
- Backup and restore
- Light and dark mode
- Mobile-friendly design

## Run Locally

Clone or download this repository and open `index.html` in a browser.

For development with automatic refresh, open the project folder in VS Code and use the Live Server extension.
