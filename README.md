# ⚡ DSA Roadmap Tracker

A free interactive Data Structures and Algorithms learning platform.

Learn DSA from beginner to advanced level with a structured roadmap, progress tracking, practice links, personal notes, daily challenges, weekly goals and achievement badges.

## 🌐 Live Website

[https://dsa-roadmap-tracker.onrender.com/](https://dsa-roadmap-tracker.onrender.com/)

## ✨ Features

- Complete DSA roadmap from Big-O notation to Dynamic Programming
- 7 learning phases with detailed topic checklists
- Progress tracking using browser LocalStorage
- Topic completion percentage and overall progress bar
- Daily DSA coding challenge
- Direct practice problem links
- Personal notes for every DSA topic
- Weekly study goal tracker
- Achievement badge system
- Day streak counter
- Search topics, concepts and practice questions
- Filter topics: All, Not Started, In Progress and Completed
- Light and dark theme
- Backup and restore learning progress
- Print / Save roadmap as PDF
- Mobile responsive design
- SEO-ready with `robots.txt` and `sitemap.xml`

## 🚀 Run Locally

1. Download or clone this repository.

```bash
git clone [https://github.com/YOUR_GITHUB_USERNAME/dsa-roadmap-tracker.git](https://github.com/YOUR_GITHUB_USERNAME/dsa-roadmap-tracker.git)
```

2. Open the project folder.

```bash
cd dsa-roadmap-tracker
```

3. Open `index.html` in your browser.

For the best development experience, use VS Code with the **Live Server** extension:

1. Open the project folder in VS Code.
2. Right-click `index.html`.
3. Click **Open with Live Server**.

## ☁️ Deploy on Render

1. Push the project to GitHub.
2. Sign in to [Render](https://render.com/) using GitHub.
3. Click **New + → Static Site**.
4. Select this repository.
5. Configure:

```text
Build Command: Leave empty
Publish Directory: .
```

6. Click **Create Static Site**.

Render deploys the website and provides a free URL:

```text
[https://your-project-name.onrender.com](https://your-project-name.onrender.com)
```

## 💾 Progress Storage

This website stores learning progress, notes, streaks and goals in browser LocalStorage.

Your data stays on your current browser/device.

Use:

```text
Backup
```

to download your progress as a `.json` file.

Use:

```text
Restore
```

to import progress on another browser or device.
