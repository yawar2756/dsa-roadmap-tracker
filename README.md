# ⚡ DSA Roadmap Tracker

A free interactive Data Structures and Algorithms learning platform.

Learn DSA from beginner to advanced level with a structured roadmap, progress tracking, practice links, personal notes, daily challenges, weekly goals and achievement badges.

## 🌐 Live Website

[https://dsa-roadmap-tracker.onrender.com/](https://dsa-roadmap-tracker.onrender.com/)

## 💻 Source Code

[View GitHub Repository](https://github.com/yawar2756/dsa-roadmap-tracker)

## ✨ Features

- Complete DSA roadmap from Big-O notation to Dynamic Programming
- 7 learning phases with detailed topic checklists
- Progress tracking using browser LocalStorage
- Topic completion percentage and overall progress bar
- Daily DSA coding challenge
- Direct practice problem links
- Personal notes for every DSA topic
- Weekly study goal tracker
- Achievement badge system
- Day streak counter
- Search topics, concepts and practice questions
- Filter topics: All, Not Started, In Progress and Completed
- Light and dark theme
- Backup and restore learning progress
- Print / Save roadmap as PDF
- Mobile responsive design
- SEO-ready with `robots.txt` and `sitemap.xml`

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone [https://github.com/yawar2756/dsa-roadmap-tracker.git](https://github.com/yawar2756/dsa-roadmap-tracker.git)
```

### 2. Enter the project folder

```bash
cd dsa-roadmap-tracker
```

### 3. Run the website

Open:

```text
index.html
```

in your browser.

### Recommended: Use VS Code Live Server

1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Click **Open with Live Server**.

The website will normally open at:

```text
http://127.0.0.1:5500/
```

## ☁️ Deploy on Render

1. Push your project to GitHub.
2. Sign in to [Render](https://render.com/) using your GitHub account.
3. Click:

```text
New + → Static Site
```

4. Select this repository:

```text
yawar2756/dsa-roadmap-tracker
```

5. Use these settings:

```text
Build Command: Leave empty
Publish Directory: .
```

6. Click:

```text
Create Static Site
```

Render automatically deploys every future GitHub push from the `main` branch.

## 💾 Progress Storage

This project uses browser LocalStorage.

It saves:

- Completed DSA checkpoints
- Completed practice problems
- Personal notes
- Daily challenge completion
- Day streak
- Weekly goals
- Achievement badge progress
- Theme preference

Your progress stays in the browser/device you use.

Use:

```text
⬇ Backup
```

to download your progress as a JSON file.

Use:

```text
⬆ Restore
```

to import your progress on another device or browser.

## 🔍 SEO Setup

This project includes:

```text
robots.txt
sitemap.xml

Open Graph tags
Schema.org structured data

```

### Google Search Console steps

1. Deploy the website on Render.
2. Open [Google Search Console](https://search.google.com/search-console/).
3. Add your Render website URL.
4. Verify ownership using the HTML meta tag.
5. Submit:

```text
sitemap.xml
```

6. Use URL Inspection.
7. Click:

```text
Test Live URL → Request Indexing
```
