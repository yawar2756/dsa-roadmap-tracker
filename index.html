Free DSA Roadmap for Beginners

Follow this interactive Data Structures and Algorithms roadmap to learn DSA step by step. Start with time complexity, arrays and strings, then move through linked lists, stacks, queues, recursion, trees, graphs, sorting, greedy algorithms and dynamic programming.

DSA Topics Covered

  • Big-O notation, time complexity and space complexity
  • Arrays, strings, two pointers, sliding window and prefix sums
  • Hash tables, linked lists, stacks, queues and deques
  • Recursion, divide and conquer, and backtracking
  • Binary trees, binary search trees, heaps and tries
  • Graphs, BFS, DFS, Dijkstra, topological sort and Union-Find
  • Sorting algorithms, binary search and greedy algorithms
  • Dynamic programming from beginner to advanced level

14-Week DSA Learning Plan

Complete the foundations during Week 1, linear data structures in Weeks 2–3, recursion and backtracking in Weeks 4–5, trees in Weeks 6–8, graphs and sorting in Weeks 9–11, and dynamic programming in Weeks 12–14. Use the final advanced section for interview preparation, competitive programming and revision.
